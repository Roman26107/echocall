# Jitsi embedded UI overlay

Необязательная надстройка скрывает стандартную панель Jitsi и добавляет
перемещаемое локальное превью. Основной application image её не собирает.

Базовый Jitsi image не поставляется с проектом. Перед сборкой выберите доступный
вам образ с совместимой структурой `/usr/share/jitsi-meet/index.html`, каталогом
`libs/` и ожидаемым DOM локального видео. Передайте его полное имя с фиксированным
тегом или digest в `JITSI_WEB_BASE`:

```bash
export JITSI_WEB_BASE=your-registry/jitsi-web:your-tested-tag
docker build --build-arg JITSI_WEB_BASE="$JITSI_WEB_BASE" \
  -t echocall-jitsi-web:local docker/jitsi-web
```

Имя выше — шаблон, а не опубликованный образ. Значение по умолчанию намеренно
не задано: сборка без выбранного образа должна завершаться ошибкой, а не пытаться
загрузить приватный образ исходной установки.

CSS и JavaScript рассчитаны на определённую структуру интерфейса Jitsi. После
обновления базового образа проверьте оба направления видео, локальное превью,
перетаскивание мышью и касанием, смену камеры и доступность элементов управления.
Runtime-тест DOM-макета не заменяет проверку с реальным Jitsi и устройствами.
